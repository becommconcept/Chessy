# Aperçus du site

Captures d'écran de la proposition, prises sur la version compilée avec le
contenu de démonstration installé par `npm run setup`.

Les réglages d'affichage sont ceux du site ; les captures sont prises avec les
animations réduites pour que chaque section apparaisse en entier.
